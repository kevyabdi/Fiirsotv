# Fiirso

A full-stack streaming platform with a viewer-facing app and an admin content management panel.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 8080)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string (provisioned via Replit DB)
- Required env: `SESSION_SECRET` — JWT signing secret for admin auth

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)
- Frontend: React + Vite + Tailwind CSS + shadcn/ui + Wouter

## Where things live

- `lib/db/src/schema/` — DB schema (categories, movies, series, seasons, episodes, users, banners, ratings, reviews, settings)
- `lib/api-spec/openapi.yaml` — OpenAPI contract (source of truth for API types)
- `lib/api-client-react/src/generated/` — generated React Query hooks
- `lib/api-zod/src/generated/` — generated Zod schemas (used by API server)
- `artifacts/api-server/src/routes/` — Express route handlers
- `artifacts/streamvault/src/` — viewer-facing streaming app
- `artifacts/admin/src/` — admin content management panel

## Architecture decisions

- Contract-first API: OpenAPI spec → Orval codegen → typed hooks + Zod schemas; no hand-written types
- JWT-based admin auth: `SESSION_SECRET` env var; only `role: admin` users can access admin routes
- Shared proxy routing: `/api` → API server, `/` → streamvault, `/admin/` → admin panel
- DB schema push on dev via `drizzle-kit push`; prod schema managed by Replit publish flow

## Product

- **Fiirso** — a Netflix-style streaming platform
- **Streaming app** (`/`): Browse movies and TV series, search, watch trailers, view details
- **Admin panel** (`/admin/`): Sign in as admin, manage movies/series/seasons/episodes/categories/banners, import from TMDB, view analytics

## Gotchas

- Run `pnpm --filter @workspace/api-spec run codegen` after any OpenAPI spec change before editing route files
- API routes import Zod schema names generated by Orval — grep `lib/api-zod/src/generated/api.ts` to get exact names
- Admin auth uses JWT via `SESSION_SECRET`; create an admin user in the `users` table with `role = 'admin'`
- The `adm-zip` dev dependency at root was added for the ZIP extraction script — safe to remove if unneeded
